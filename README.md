# 矢量着陆 · Vector Lander — 太阳系航线

一款纯 Canvas 手写牛顿力学的矢量风格着陆游戏。向 **Spacewar! (1962)** / **Lunar Lander (1969/1979)** / **Asteroids (1979)** 致敬。

**单文件、零依赖、无构建步骤**——直接双击 `vector-lander/index.html` 即可运行，也支持手机触屏。

```
vector-lander/index.html   ← 游戏本体（唯一必需文件）
```

---

## 玩法

你驾驶一艘只有旋转与主引擎的飞船，在真实惯性下把飞船**慢速、直立**地降落在发光平台上。

| 项目 | 安全阈值 |
|---|---|
| 下降速度 | ≤ 36 |
| 横向速度 | ≤ 26 |
| 姿态倾角 | ≤ 约 35° |
| 落点 | 必须在平台范围内 |

松开按键飞船会继续漂移——惯性是真实存在的，这是本作的核心手感。

### 操作

| 按键 | 作用 |
|---|---|
| ← → / A D | 旋转机头 |
| ↑ / W / 空格 | 主引擎（消耗燃料） |
| G / ⚙ | 参数设置面板（实时生效） |
| P | 暂停 |
| M | 静音 |
| R | 重置本关位置 |
| ESC | 返回航线图 |

触屏设备自动显示 ◀ ▶ ▲ 三个虚拟按键。手机端建议横屏游玩；竖屏会提示旋转，也可选择继续竖屏。

## 太阳系航线：十站战役

每站都有独立的重力、配色主题、天象与障碍机制，难度 D1 → D10 递进。

| # | 站点 | 天体 | D | 核心机制 |
|---|---|---|---|---|
| 1 | 静海 | 月球 | D1 | 教学关：宽平台、低重力 |
| 2 | 风暴洋 | 月球 | D2 | 慢速漂移陨石 |
| 3 | 暗面 | 月球 | D3 | 低能见度（潮汐锁定，永远看不到地球） |
| 4 | 小行星带 | — | D4 | 陨石雨（红色预警线 + 天顶坠落） |
| 5 | 水手谷 | 火星 | D5 | 大气阻力 + 尘暴侧风 + 沙尘暴爆发 |
| 6 | 引力井 | 火卫一 | D6 | 点质量引力井（r² 衰减）+ 径向岩柱 |
| 7 | 火山地带 | 木卫一 | D7 | 间歇泉（喷发前黄光预警）+ 岩柱 |
| 8 | 冰原 | 木卫二 | D8 | 强横风 + 冰筏滑移平台 |
| 9 | 云海 | 木星 | D9 | 无地面！浮空坞站 + 风暴周期 |
| 10 | 斯普特尼克 | 冥王星 | D10 | 低能见度 + 预测线干扰 + 陨石雨 |

### 进度系统

- **星级评价**：每次着陆按剩余燃料与触地柔和度评 ★1~3
- **解锁链**：通关一站解锁下一站（设置面板可开「解锁全部」）
- **航行统计**：成功着陆数 / 坠毁数 / 完美着陆（三星）/ 最佳航行
- 全部进度保存在 `localStorage`

## 技术实现

### 物理

- **半隐式欧拉积分**，固定步长 **120 Hz**（渲染插值），保证不同刷新率下手感一致
- `envForces()` 统一封装所有环境力：点质量引力 / 均匀重力 / 风 / 大气阻力 / 沙尘暴 / 间歇泉 —— **物理模拟与轨迹预测共用同一份代码**，所以预测虚线与实际飞行严格一致
- 轨迹预测还会按时间推算**移动平台**的位置，木星/木卫二关同样准确

### 三个平台形态

| 形态 | 适用 | 表现 |
|---|---|---|
| 发射台 | 固体内表面 | 台板 + 着陆圈 + 桁架塔（×N 挂牌在塔上） |
| 冰筏 | 木卫二 | 小船造型，沿冰面滑移，着陆后飞船随筏移动 |
| 天空坞站 | 木星 | 栏杆 + 底部悬浮喷流 + 天线 |

另有**垂直定位光柱**，远距离与低能见度下依旧能锁定落点。

### 天象

每站按天文学常识配置天空天体：月球正面挂地球、暗面只有银河（潮汐锁定）、火星见火卫一与地球晨星、火卫一挂大火星、木卫一二挂巨大木星、冥王星挂卡戎。天体带小标签，避免误认。

### 音频

全部**程序化合成**（Web Audio），零音频素材：引擎噪声随推力连续调制音色、爆炸噪声、着陆钟声、按天体切换的环境音。

### 设置面板（G）

重力倍率、主引擎推力、燃料消耗率、安全速度阈值、平台宽度、初始离地高度、飞船数量、飞船外观（经典矢量 / 猎鹰 9 / 星舰）、飞行拖尾、解锁全部、屏幕震动——全部实时生效并持久保存。

## 已知取舍

- 单文件是为了「发给朋友就能玩」，代价是没有模块拆分与自动化测试；所有验收依靠浏览器内自动化钩子（`window.game`）逐项验证
- 存档使用 `localStorage`，清浏览器数据会丢失进度
