# 矢量着陆 · Vector Lander — 太阳系航线

一款纯 Canvas 手写牛顿力学的矢量风格着陆游戏。向 **Spacewar! (1962)** / **Lunar Lander (1969/1979)** / **Asteroids (1979)** 致敬。

**单文件、零依赖、无构建步骤**——直接双击 `vector-lander/index.html` 即可运行，也支持手机触屏。

```
vector-lander/index.html   ← 游戏本体（唯一必需文件）
```

---

## 开始试玩

当前正式游戏可直接打开 GitHub Pages。候选版本请使用 Bridge 版本登记表给出的固定提交链接，在主菜单左下角核对版本。手机可在设置中切换兼容横屏，固定地址也支持追加 `?compat=1`。 [正式游戏](https://timer009.github.io/Spacer/vector-lander/) · [版本登记表](https://github.com/Timer009/spacer-gai-bridge/blob/main/RELEASE-VERSIONS.md)

主菜单的「玩法指南」介绍操作、仪表和回收规则，可预约下次飞行重看简短引导。燃料耗尽约 1.5 秒后，在任务仍进行时可继续随惯性漂流，或结束任务返回对应模式入口。

## 发布版本

游戏从 HTML 内置的 `BUILD` 显示版本。主菜单左下角可快速核对，设置页可复制完整版本资料。`BUILD` 记录版本号、构建编号、UTC 构建时间及发布渠道。浏览器取到旧文件时会显示旧文件自己的标识。

发布候选使用 `v2.0.<Sprint>-rc.<N>`，首次候选从 1 开始，每次交付递增。正式归档时使用 `v2.0.<Sprint>`，继续递增该 Sprint 的构建编号，更新构建时间及发布渠道。提交后在 Bridge 登记构建与完整 Git SHA，并以该 SHA 固定试玩链接。

## 玩法

你驾驶一艘只有旋转与主引擎的飞船，在真实惯性下把飞船**慢速、直立**地降落在发光平台上。

| 项目 | 普通着陆默认阈值 |
|---|---|
| 下降速度 | ≤ 36 |
| 横向速度 | ≤ 26 |
| 姿态倾角 | ≤ 约 35° |
| 落点 | 支脚从上方接触平台 |

松开按键飞船会继续漂移——惯性是真实存在的，这是本作的核心手感。

平台的「得分×N」表示战役着陆基础分为 400 × N。剩余燃料和柔和着陆的奖励另计。

### 操作

| 按键 | 作用 |
|---|---|
| ← → / A D | 旋转机头 |
| ↑ / W / 空格 | 主引擎（消耗燃料） |
| G / ⚙ | 参数设置面板（实时生效） |
| P | 暂停 |
| M | 静音 |
| R | 重置本关位置 |
| ESC | 返回当前玩法或主菜单 |

触屏设备自动显示 ◀ ▶ ▲ 三个虚拟按键。手机端建议横屏游玩；竖屏会提示旋转，也可选择继续竖屏。

## 三种玩法

- **太阳系战役**沿用原有十站、飞船数量、星级、解锁与统计。当前十个任务均指定轻型月面着陆器。
- **自由飞行**可练习任一场景，选择轻型月面着陆器、猎鹰 9 或星舰。火卫一是低惯量练习场，仅开放轻型月面着陆器和猎鹰 9。可无限重试，结果与战役存档分开。
- **回收挑战**开放 Falcon 9 海上回收。观察甲板的横移、升沉和倾角，修正海风造成的漂移，让支脚落在甲板内。HUD 显示相对甲板的横移和下降速度，挑战可无限重试，独立于战役存档。Super Heavy 挑战锁定重型助推器。让上部金色挂点进入双臂之间，控制横向偏移、相对速度与倾角，捕获后由机械臂闭合承载。

### 太阳系战役的十站航线

每站都有独立的重力、配色主题、天象与障碍机制，难度 D1 → D10 递进。

| # | 站点 | 天体 | D | 核心机制 |
|---|---|---|---|---|
| 1 | 静海 | 月球 | D1 | 教学关：宽平台、低重力 |
| 2 | 风暴洋 | 月球 | D2 | 慢速漂移陨石 |
| 3 | 暗面 | 月球 | D3 | 低能见度（潮汐锁定，永远看不到地球） |
| 4 | 小行星带 | — | D4 | 陨石雨（红色预警线 + 天顶坠落） |
| 5 | 水手谷 | 火星 | D5 | 大气阻力 + 尘暴侧风 + 沙尘暴爆发 |
| 6 | 引力井 | 火卫一 | D6 | 点质量引力井（r² 衰减）+ 径向岩柱 |
| 7 | 火山地带 | 木卫一 | D7 | 间歇泉（喷发前黄光预警）+ 岩柱 |
| 8 | 冰原 | 木卫二 | D8 | 强横风 + 冰筏滑移平台 |
| 9 | 云海 | 木星 | D9 | 无地面！浮空坞站 + 风暴周期 |
| 10 | 斯普特尼克 | 冥王星 | D10 | 低能见度 + 预测线干扰 + 陨石雨 |

### 进度系统

- **星级评价**：每次着陆按剩余燃料与触地柔和度评 ★1~3
- **解锁链**：通关一站解锁下一站（设置面板可开「解锁全部」）
- **航行统计**：成功着陆数 / 坠毁数 / 完美着陆（三星）/ 最佳航行
- 全部进度保存在 `localStorage`

## 技术实现

### 物理

- **半隐式欧拉积分**，固定步长 **120 Hz**，将模拟步长与画面刷新分开
- `envForces()` 统一封装所有环境力：点质量引力 / 均匀重力 / 风 / 大气阻力 / 沙尘暴 / 间歇泉 —— **物理模拟与轨迹预测共用同一份代码**。预测按当前输入持续推演，也考虑姿态、剩余燃料和已知障碍
- 轨迹预测会推算**移动平台**的位置，按高度、下降速度与重力调整视距，最多 24 秒。尚未预警的随机陨石不进入预测

### 三个平台形态

| 形态 | 适用 | 表现 |
|---|---|---|
| 发射台 | 固体内表面 | 台板 + 着陆圈 + 桁架塔（得分×N 标牌位于台面下方） |
| 冰筏 | 木卫二 | 小船造型，沿冰面滑移，着陆后飞船随筏移动 |
| 天空坞站 | 木星 | 栏杆 + 底部悬浮喷流 + 天线 |

另有**垂直定位光柱**，远距离与低能见度下依旧能锁定落点。

### 天象

每站按天文学常识配置天空天体：月球正面挂地球、暗面只有银河（潮汐锁定）、火星见火卫一与地球晨星、火卫一挂大火星、木卫一二挂巨大木星、冥王星挂卡戎。天体带小标签，避免误认。

### 音频

全部**程序化合成**（Web Audio），零音频素材：引擎噪声随推力连续调制音色、爆炸噪声、着陆钟声、按天体切换的环境音。

### 设置面板（G）

画质、重力、基准推力、基准耗油、安全阈值、平台尺寸、飞船数量、自由飞行默认型号、飞行拖尾、解锁选项和震动设置均可保存。自动／高／中／低画质调整渲染细节，物理步长和碰撞判定保持一致。本次任务使用起飞时确定的型号。

### 飞船型号

| 型号 | 手感 |
|---|---|
| 轻型月面着陆器 | 沿用 Sprint 09 的直接转向、推力及燃料 |
| 猎鹰 9 | 更高推力和燃料容量，转向需要加速和制动 |
| 星舰 | 最大燃料容量和更高转动惯量，需更早开始转向 |

推力、耗油与质量采用游戏单位。猎鹰 9 和星舰的质量与转动惯量随燃料变化。实际飞行和预测共用型号、控制积分与接触点。燃料星级按各型号剩余比例评定，燃料得分折算为关卡的基准油量。

## 已知限制与测试

- 夸克的原生横屏兼容暂缓。页面在支持的浏览器中可使用兼容横屏。
- 进度及设置存于当前浏览器的站点数据。正式 Pages、首次从本地打开和第三方预览是不同来源。
- 安装 Playwright 和 Chromium、WebKit、Firefox 后，在仓库根目录运行 `node tests/mobile-hotfix.cjs`。可传入 `chromium`、`webkit` 或 `firefox` 单独跑一种引擎。若配置 `SPACER_TEST_EDGE` 指向 Edge 可执行文件，套件会增加 Edge。
- Playwright 的 WebKit 和触屏视口属于浏览器模拟。移动浏览器的系统菜单、实际帧率、温升和长时间内存还需真机确认。
- 存档使用 `localStorage`，清浏览器数据会丢失进度
